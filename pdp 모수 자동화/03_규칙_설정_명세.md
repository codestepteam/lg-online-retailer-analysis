# 03. 규칙 → 설정 파일 명세

작성일: 2026-11-06. 목적: 10월에 코드·대화·CSV 정정에 흩어진 판정 규칙을 **기계가 읽는 설정 항목**으로 번역한다. Opus는 이 표를 보고 설정 파일과 그것을 읽는 코드를 만든다. 사용자는 이 표만 보고 "규칙이 빠졌다·틀렸다"를 짚을 수 있어야 한다.

상태 표시:
- **확정** = 사용자 결정(D번호) 또는 두레이·EY 원문(#번호)에 근거.
- **확인 필요** = 두 출처가 어긋나거나 아직 아무도 정하지 않음. 07 문서에 모아 둠.
- **AI 제안** = 10월 코드에서 AI가 임의로 넣은 것. 사용자 확인 전까지는 "확인 필요" 행으로만 쓰고 제외 근거로 쓰지 않음.

외국어 문구는 원어 옆 괄호에 한국어 뜻을 적는다(D102).

## 0. 설정 파일 묶음 (이름은 후보, 07 문서에서 확정)

설정은 코드와 분리해 `runs/{YYYY-MM}/config/` 아래 둔다. 매달 S0 단계가 EY 엑셀에서 자동 생성하는 파일과, 사람이 유지하는 파일을 나눈다.

| 후보 파일명 | 내용 | 누가 만드나 |
| --- | --- | --- |
| `targets.json` | 국가·리테일러·OSM 보유 여부·흐름(OSM/검색)·국가 코드 | S0 자동(엑셀 `대상 국가,리테일러` 시트) + 콘솔 `fixed-targets.json` 대조 |
| `brands.json` | 국가·리테일러·제품군별 대상 브랜드와 표기 변형 | S0 자동(엑셀 `경쟁브랜드` 시트) + 독일·영국 보강(#110) |
| `search_terms.json` | 검색어(J열)·제품군(F열)·엑셀 행번호·제외 표시 | S0 자동(엑셀 `Search Term` 시트) |
| `keywords.json` | 국가별 리리부 키워드(종류: 리퍼·리셀·부품) | S0 자동(엑셀 `제외키워드(리리부)` 오른쪽 25개국 표) |
| `categories.json` | 제품군 판별 정규식(긍정·부정), 냉동고 처리 | 사람 유지(아래 3장) |
| `retailer_rules.json` | 리테일러별 URL 규칙·문구·판매자 규칙·페이지 상태 문구 | 사람 유지(아래 4~6장) |
| `osm_query.json` | 콘솔 04 쿼리 옵션·기준일 규칙 파라미터 | 사람 유지(아래 7장) |
| `output.json` | 26열 이름·공유용 변환표·파일명 틀·버전 | 사람 유지(아래 8장) |

## 5. 리테일러별 규칙 (`retailer_rules.{국가}.{리테일러}`)

각 항목은 ⟨어디서 보나⟩ → ⟨무엇을 보나⟩ → ⟨결과⟩ 순이다. "본 상품 영역"은 추천 상품·다른 판매자 목록을 제외한 주 상품 블록을 뜻한다.

| 국가·리테일러 | 규칙 | 출처 | 상태 |
| --- | --- | --- | --- |
| 스페인 MediaMarkt | PDP 제목 `REACONDICIONADO`(재생품) → 리퍼 제외. 본 상품 `Vendido y enviado por`(판매 및 배송: …) 뒤 외부 판매자가 확인되면 제외. 추천 문구는 무시하고, 문구가 없으면 본 상품 ID의 내부 판매자 값으로 보조 판정 | #74·D067·D124, `mediamarkt_screen.py` | 확정·로컬 구현 |
