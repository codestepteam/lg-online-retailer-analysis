# PDP 모수 수집 자동화

PDP 모수 = 진단할 상품 상세 페이지 URL 목록(25개국 35개 리테일러). 10월 첫 수집은 AI와 대화하며 진행했고, 자동화 회귀 비교 기준은 [`pdp 모수 추출/최종_20261029/`](../pdp%20모수%20추출/최종_20261029/READ.md)의 공유용 v5다. 이 폴더는 **11월부터 같은 일을 스크립트로 매달 반복**하기 위한 계획·설계·코드를 보관한다.

## 현재 상태

- 2026-11-10 D127: Sharaf DG PDP 모수 검색에 `Sold By Sharaf DG`(Sharaf DG 직판) 토글 ON 조건을 필수로 반영했다. 11월 검색 설정·첫/다음 페이지·과거 무필터 기록 재사용 방지와 `promo` URL 보존의 [무료 검증 기록](../outputs/sharaf-direct-rule-20261110-839fcfd6/README.md)을 따른다. 새 유료 수집은 실행하지 않았다.
- 2026-11-10: MediaMarkt 4개국의 OSM 여부와 무관한 PDP 제목·본 상품 판매자 검사를 확인·보강했다. 승인된 헝가리·네덜란드 546주소를 실패 0개로 재검사해 네덜란드 4개를 추가 제외한 [공유용 v6](../outputs/mediamarkt-hu-nl-v6-20261110/README.md)를 생성했다. 자동화의 10월 회귀 비교 원본은 v5를 계속 보존한다(D124).
- 2026-11-06 계획 문서 8개를 작성한 뒤 `pipeline/`에 설정·OSM 후보·검색·필터·PDP 확인·판매자 판정·공유본 생성 코드와 테스트를 추가했다.
- 다음: [05 작업 목록](05_구현_작업목록.md)의 완료 기준에 따라 11월 전체 자동 회차의 실행·결과를 확인한다. 코드가 있다는 사실을 전체 회차 완료로 해석하지 않는다.

## 10월 폴더와의 관계

- `pdp 모수 추출/`과 `outputs/`는 **읽기 전용 비교 자료**다. 10월 입력을 11월 코드에 넣어 v5 최종 판정과 같은지 확인하는 데만 쓴다. 10월의 v1→v5 과정은 되풀이하지 않는다. 옮기거나 고치지 않는다.
- 결정 기록은 계속 [`docs/DECISIONS.md`](../docs/DECISIONS.md)에 한다(이 세션 결정은 D105~D115).
- 유료 호출(Zyte·BigQuery)·외부 전송·커밋은 사용자 승인 뒤에만.
