# 05. 구현 작업 목록 (Opus용)

작성일: 2026-11-06. 대상: 세부 구현을 맡는 Opus 세션. 각 작업 묶음(WP)은 **입력 → 출력 → 재사용 코드 → 완료 기준 → 유료 호출 여부** 순으로 적었다. 순서대로 하되, WP1(Zyte 실험)은 WP2~WP5와 병렬로 진행할 수 있다.

공통 규칙:
- 코드는 `pdp 모수 자동화/pipeline/` 아래에만 만든다. 10월 폴더 `pdp 모수 추출/`과 `outputs/`는 읽기 전용.
- 모든 유료·외부 호출(Zyte·BigQuery)은 `--dry-run` 기본. 건수·예상 비용을 출력하고 사용자 "진행" 뒤 `--run`.
- 새 파일·모듈 이름은 후보를 제시하고 사용자 의견을 받는다(글로벌 규칙). 이 문서의 이름은 모두 후보다.
- 규칙 값은 코드에 적지 않고 `config/`에서 읽는다. 값 출처는 [03 명세](03_규칙_설정_명세.md).
- 커밋은 사용자가 요청할 때만. 커밋 메시지에 공동작성자·생성 서명을 넣지 않는다.
