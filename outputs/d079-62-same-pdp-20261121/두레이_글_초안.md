# [확인 요청] Costco, Falabella에서 주소 글자만 다른 62쌍을 중복으로 제외해도 되는지

안녕하세요. PDP 모수 v8.1의 중복 제외 중 한 묶음에 대해 확인을 부탁드립니다.

## 배경

- 합의한 중복 기준은 '접속 후 URL이 같을 때만 중복'입니다.
- v8.1에는 접속 후 URL의 상품명 글자만 서로 다르고 주소 끝의 PDP 식별자(리테일러 내에서 사용하는 PDP 식별자)는 같은 행이 62쌍 있습니다(Costco 캐나다 43쌍, Falabella 칠레 19쌍).
- 이 기준 그대로면 이 62쌍의 두 행은 주소가 달라 둘 다 포함 대상입니다.
- 현재 v8.1에서는 쌍마다 한 행만 포함이고, 나머지 62행은 '주소 끝 PDP 식별자가 같으면 같은 상품'으로 보고 제외단계 '④중복'으로 제외해 두었습니다. 이 판단은 합의한 기준에 없는 것이라 확인을 받고자 합니다.

## 확인한 방법

- 62쌍 124행의 접속 후 URL을 2026-11-21에 사이트에서 다시 열었습니다. 한 쌍의 두 주소는 같은 도구, 같은 설정, 같은 화면 크기로 연달아 열었습니다. 데스크톱 Chrome 브라우저를 썼고, 값을 읽은 것과 같은 접속에서 페이지 전체 그림을 함께 저장했습니다.
- 페이지 원본과 화면 그림을 저장하고, 원본에서 값을 프로그램으로 뽑아 글자 단위로 비교했습니다.
- 비교한 항목은 14개입니다: 화면에 보이는 제품 번호, canonical, 브랜드와 모델, 상품명, 갤러리, Feature, 상세 설명 본문, 사양표, 평점과 리뷰 수, 표시 가격, 판매자, 구매 가능 상태, 선택 옵션, 카테고리 경로.
- 14개가 모두 일치해야 '같음'으로 판정했습니다. 주소, 제목, 10월 저장 기록만으로 같다고 하지 않았습니다.
