국가 선택, Raw Table 종류 전환, 키보드로 여는 지표 도움말을 확인했습니다.

프런트 검사

기존 테스트 7건과 Vite 빌드를 실행했습니다.

  • 초록 상태의 경계는 프로젝트의 확정 기준인 80% 이상을 사용합니다. Visibility(노출) 지표에는 준수율 신호등을 적용하지 않습니다.
  • 헤더·탭·공통 필터는 4~6장에 적힌 글자 규격을 우선합니다. 22장 공통 글자 단계는 콘텐츠 안의 제목, 점수, 설명에 적용했습니다. 데이터가 많은 표는 기존의 조밀한 글자 크기를 유지했습니다.
  • 경쟁사 고유색을 유지하고 삼성의 파랑은 가이드의 파랑으로 맞췄습니다. 순위와 ATA(자사와 경쟁사 간 비교 지수)의 기존 숫자 단위를 사용합니다.
  • 단일 필터의 펼침 목록 꾸미기는 브라우저 지원 범위에 따릅니다. 좁은 화면에서는 글자와 안쪽 여백을 줄입니다.
