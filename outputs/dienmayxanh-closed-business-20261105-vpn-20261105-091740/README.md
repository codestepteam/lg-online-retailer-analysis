## v3 포함 원인 (기존 코드와 저장 판정의 확인 결과)

1. `판정근거/스크립트/step1_filter.py`의 `osm_rows`는 OSM 원본의 브랜드·제품군·URL·기준일 등을 가져오지만 `AVLBL_STAT`를 판정 행에 넣지 않는다(124~137행). 따라서 `\N`을 재고 있음으로 해석한 로직도, `Out of stock`을 제외한 로직도 없다.
2. `판정근거/스크립트/page_check.py`는 HTTP 200과 상품 제목이 있는 페이지를 `정상`으로 둔다. `영구품절`은 410 응답과 특정 다국어 문구의 조합에서만 지정한다(21~25행). 200 응답의 `NGƯNG KINH DOANH`는 검사하지 않는다.
3. `판정근거/스크립트/step2_page_seller.py`는 `정상` 페이지의 판매자·중복 등을 판단한다(53~93행). 판매 중단 문구나 OSM 재고값은 확인하지 않는다. 예시 행 11752의 당시 `pages_best.jsonl` 기록도 HTTP 200·`페이지상태=정상`, `seller_g4.csv`는 직판이다.

따라서 현 코드의 포함 판정은 판매 가능 확인을 뜻하지 않는다. 현재 발견된 44개가 10월 19일이나 v3 작성 당시에도 판매 중단 상태였는지는 그 시점의 원본 HTML이 확보되지 않아 이 조사로 확정할 수 없다.
