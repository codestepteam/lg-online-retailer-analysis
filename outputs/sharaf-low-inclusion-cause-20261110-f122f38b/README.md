## 토글이 판매 제안 URL을 바꾸는 직접 관찰

같은 세션·같은 검색어 `bottom freezer refrigerator`의 토글 OFF/ON 첫 48개 카드 관찰에서 아래 동일 상품번호의 판매자·promo가 달랐다. 관찰 시각은 verification.json에 저장했다. 원본은 `outputs/sharaf-toggle-causality-20261110-5972e8b2/search-observations.json`이다.

이는 토글 미적용 목록이 외부 판매자 판매 제안을 대표 URL로 내보내고, 토글 ON 목록이 같은 상품의 직판 판매 제안을 내보내는 작동 사례다. 기존 수집 코드가 대표 링크만 가져가는 방식과 연결된다. 앞서 예시로 사용한 **Bosch KIV87NSE0M은 오늘 OFF에서도 직판으로 나왔으므로 토글 효과의 직접 예시로 쓰지 않는다.** 해당 제품의 구 promo가 외부 판매자이고 신 promo가 직판인 사실과, 토글이 그 변화를 일으켰는지는 별개다.

## 결론과 확인 범위

기존 포함이 적었던 처리상의 원인은 **직판 판매 제안을 확보하지 않은 검색 목록의 대표 URL만 수집하고, 외부 판매자 URL은 제외한 뒤 같은 제품의 직판 URL을 보충하지 않는 방식**이었다. 93개 제품의 기존 제외와 이번 포함, 같은 시점 토글 OFF/ON에서 3개 제품의 판매자 전환, 해당 OFF URL이 실제 기존 제외 URL과 같은 점으로 확인했다.
