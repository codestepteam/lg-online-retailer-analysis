1. `판정근거/스크립트/step1_filter.py`의 `osm_rows`(124~137행)는 OSM의 `AVLBL_STAT`를 판정 행으로 전달하지 않는다. 상품명·브랜드·제품군·URL 등으로 1차 판정했다.
