# [두레이 157](https://codestep.dooray.com/task/4424097923196640208/4458435808136916155): UAE Sharaf DG v3 포함 URL 조사 (2026-11-05)

## 결론과 범위

- **10월 기록:** v3의 UAE Sharaf DG는 검색어로 수집한 상품카드 2,793행이며, 그중 25행( LG 8행)을 포함했다. OSM 유래가 아니다. 25행의 저장 판매자 판정은 모두 `Sharaf DG / 직판`이다.
- **보존 범위 정정:** 10월 검색 수집 결과는 `상품카드.csv` 2,793행, `상품카드_페이지원본.jsonl`의 Sharaf DG 검색 페이지 기록 63행, `검색어별_건수대조.csv`로 보존돼 있다. 보존되지 않은 것은 상품 상세 페이지(PDP)의 당시 HTML 원문이며, 검색 결과를 저장하지 않았다는 뜻이 아니다.
- **오늘 직접 접속:** 무료 HTTP 요청은 정확한 25개 `?promo=` URL 모두 Cloudflare 403이었다. 사우디 VPN 상태의 Codex 내부 브라우저 탭 5개에서는 처음 보안 확인 화면이 떴지만 잠시 뒤 상품 화면으로 전환됐고, **25개 정확한 URL을 모두 직접 확인했다**. 본 상품 판매자는 Sharaf DG 16개, 외부 판매자 9개(LG 3개)다.
- **현재 파서 불일치 재현:** 25개 현재 HTML의 첫 `seller_name`은 전부 `Sharaf DG`, 첫 `seller_type`은 전부 `first_party`다. 그런데 상품 판매 영역은 9개에서 외부 판매자 이름을 보여 준다. `seller_g4.py`의 첫 정규식 일치값 판독 방식은 현재 화면에서 9개를 잘못 직판으로 분류한다.
- **10월 원인 한계:** 당시 저장 판매자 판정표도 25개 모두 `Sharaf DG / 직판`이다. 그러나 10월 PDP HTML 원문이 저장소에 없어 당시에도 같은 HTML 불일치가 있었는지, 그 뒤 판매자가 바뀌었는지는 확정할 수 없다.

## 생성 위치에서 소비 위치까지

1. `pdp 모수 추출/검색결과_20261028_734afcdd/상품카드.csv`에 2026-10-28 검색어 9개에서 얻은 카드 2,793행과 `카드PDP링크`가 저장됐다. `검색어별_건수대조.csv`에는 검색어별 표시 수·저장 수·검색 URL이 남아 있다.
2. `pdp 모수 추출/최종_20261029/판정근거/스크립트/step1_filter.py` 138~146행은 이 `상품카드.csv`를 읽어 `흐름=검색`, 상품 URL·검색어·수집일을 만든다.
3. 같은 폴더의 `seller_g4.py` 76~86행은 당시 저장 HTML에서 **첫 번째** `seller_name`과 `seller_type` 정규식 일치값을 읽었다. `seller_type=first_party`이면 직판으로 분류했다. 그 결과가 `판매자판정/seller_g4.csv`에 남아 있다. HTML 원본은 `판정근거/README.md`에 따르면 저장소에 보존되지 않았다.
4. `step2_page_seller.py` 20~22행은 그 판매자 표를 읽고 64~82행에서 `외부판매자`를 제외, `직판`을 계속 포함 대상으로 처리했다. 이후 페이지·중복 필터를 거쳐 v3에 25행이 포함됐다.

`seller_g4.py`의 첫 일치값이 실제 `?promo=` 제안의 `Sold by`와 같았는지는 과거 HTML이 없어 검증할 수 없다. `Sold by`라는 문구 자체는 직판 상품에도 있으므로, 제외 기준은 문구 유무가 아니라 **본 상품 판매자가 Sharaf DG 이외인지**다. `Fulfilled by Sharaf DG`는 배송 주체 표시이며 판매자 이름을 대체하지 않는다.

## 2026-11-05 변경 대상 CSV 확인

`prepare_change_input.py`로 v3의 Sharaf DG 포함 25행과 09:53 KST 내부 브라우저 판매자 기록 25행의 행번호·정확한 `?promo=` URL을 대조한 뒤, 외부 판매자 9행(LG 3행)을 추렸다. `build_change_csv.mjs`가 원본 v3의 26열을 보존하고 변경 요청·화면 근거 10열을 추가했다. 생성 후 9개 행번호·원본 26열·현재 판매자·다운로드 복사본의 SHA-256 일치를 다시 확인했다. 원본 v3는 수정하지 않았다.

같은 날 추가 확인을 위해 새로 연 내부 브라우저 탭 5개는 Cloudflare 보안 확인 화면에 머물렀다. 따라서 이 CSV의 현재 판매자 근거 시각은 앞서 상품 페이지까지 도달한 **09:53 KST 확인 기록**이다. 당시 PDP HTML 원문은 보존되지 않았으므로 10월 판정 오류와 이후 판매자 변경은 구분할 수 없다.
