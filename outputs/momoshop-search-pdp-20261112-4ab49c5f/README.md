# 2026-11-12 대만 MomoShop 검색어 재수집

EY 진단 항목 v2.2의 `Search Term` 탭에서 11월 3일에 사용한 [11개 검색어](../momoshop-search-pdp-20261103-76f0f589/keywords.json)를 그대로 사용했다. 내부 브라우저에서 검색어별로 화면 순서 상위 1,000개 또는 마지막 페이지까지 상품 링크를 읽었다. 검색 화면의 카드와 페이지에 기록된 구조화 상품 목록의 링크·순서를 응답마다 대조했다.

| 항목 | 건수 |
| --- | ---: |
| 검색어 | 11 |
| 페이지 | 214 |
| 검색 상품 카드 | 6,256 |
| 같은 상품을 합친 후보 | 3,944 |
| 포함 판정 | 520 |
| 제외 판정 | 3,418 |
| 검토 필요 상품 | 6 |

`熱泵乾衣機`(히트펌프 건조기)는 화면의 ‘다음 페이지’를 눌러 5페이지에서 사이트가 결과 없음 안내를 표시하는 것을 확인했다. 4페이지까지의 117카드를 반영했다. 검색어별 페이지·카드 수는 [검색 요약](search_summary.json)에 있다.

상세 확인 대상은 일반 상품 556개와 입점 상점 29곳의 대표 상품이다. 내부 브라우저에서 250건을 확인했고, 당시 접속이 거부되거나 요청을 보류한 335건은 승인받은 Zyte 브라우저 HTML 335회로 확인했다. 검색과 최초 최종 상세 확인 실패는 0건이다.

재검토에서 `/TP/`(입점 상점) 경로 후보 2,468개가 모두 제외됐음을 대조했다. 이 중 948개는 입점 판매자로, 1,520개는 브랜드 단계에서 제외됐다. 일반 상품의 `福利品`(B급·전시품) 8개도 기존 EY 제외 기준으로 빠졌다. 최초 포함 상품 526개 중 303개는 저장 HTML, 64개는 브라우저에서 본 상품의 상점명과 공급사 코드를 다시 검사했다. 367개 모두 공급사 코드가 있고 입점 상점명은 없었다. 나머지 159개는 재접속 차단으로 최초 브라우저 관찰 요약과 검색 원래 주소를 근거로 판매자를 `momo (추정)`으로 표시한다.

6개는 선택 가능한 본 상품 옵션이 `無(已售完)`(옵션 없음·품절)이고 재입고 또는 판매 종료 여부를 확인할 수 없어 검토 필요로 옮겼다. 상세 판매자 데이터를 다시 읽지 못한 159개 중 158개는 검색 카드에 재고 있음으로, LG 냉장고 12290129는 품절로 표시됐다. 이 냉장고는 상세 재접속이 차단돼 구매 영역 상태가 미확인이다. [D068의 영구 품절 제외 기준](../../docs/DECISIONS.md#2026-10-29-없는-페이지와-영구-품절-페이지는-제외한다)에 따라 재입고 중 표시와 검색 재고값만으로는 영구 품절을 판정하지 않았다. [상품별 MomoShop 전용 필터 재검토 근거](momo_filter_audit.json).

v7의 대만 MomoShop은 원본 요청 주소 1,250개, 포함 10개, 제외 1,240개다. 이번 목록에서 v7의 10개 중 7개는 포함, 1개는 품절 검토 필요, 2개는 검색 결과에서 찾지 못했다. 이번에만 포함된 상품은 513개다. 11월 3일 검색 결과 443개와 이번 포함 목록은 상품 번호 341개가 겹친다.

LG Clinic에 반영할 때는 대상 운영 회차를 고르고, 포함 목록과 기존 회차를 상품 번호로 대조한다. 새 URL만 별도 PDP URL 세트로 만들어 `pipeline.local init-run` → `capture` → `parse` → `score`로 진단한다. `push` 사전 점검으로 새 URL과 진단 셀을 확인하고, 승인 후 `push --apply`로 반영한다. 11월 12일의 수집·판정은 로컬 모수 작업이다.
