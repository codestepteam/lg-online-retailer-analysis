## 판정과 검증 범위

- 정정본의 제외는 대상 브랜드 1,712행, 제품군 11행, 리리부 1,557행(부품, 리퍼, 중고 및 비대상 외부 판매자 등), 같은 Magalu 상품번호 중복 316행이다. 같은 상품번호가 여러 번 잡히면 포함 조건을 충족한 카드 중 앞 행을 남겼다. 포함은 냉장고 204개, 세탁기와 세탁건조기 140개다.
- 포함 후보와 일반 판매점 대표 상품의 상세 화면을 총 400건 열었다. 최종 포함 344건 모두에서 본 상품의 판매자를 확인했다. 일반 판매자 제외 731행은 카드의 판매자 ID와 같은 ID의 대표 상세에서 확인한 판매자 이름을 연결했다. 이 행의 개별 상세 접속 결과는 빈칸이다.
- 검색 페이지와 방문한 상품 상세의 수집 실패는 0건이다. 포함 6행은 상품 사양에서 모델명이나 참조 번호를 확인하지 못해 `제품코드`를 비웠다.
- v8.1의 10월 해외영업본부 상품 데이터(OSM) Magalu 포함 284개와 상품번호로 비교하면 공통 170개, 이번 검색에서만 포함 174개, OSM에서만 포함 114개다. 상품번호 기준 비교이며 같은 모델도 상품번호가 다르면 여러 주소가 남을 수 있다.
