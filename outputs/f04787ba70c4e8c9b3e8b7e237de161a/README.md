# 대만 Momoshop 검색어 기반 PDP 전체판정 파일 — v3와 같은 26열

`Momoshop_검색어기반_PDP모수_전체판정_6407행_20261103.xlsx`의 `전체판정` 시트와 같은 이름의 `.csv`는 검색 카드 **6,407행 전부**를 담는다. 두 파일 모두 기존 공유용 v3와 **26개 열의 이름·순서가 완전히 같다**. `모수 포함 여부`에서 **포함 443행**, **제외 5,964행**을 볼 수 있고, 제외 가운데 `④중복`은 1,420행이다.

같은 상품이 여러 검색어 또는 페이지에 나오면 첫 포함 행만 `포함`이고 나머지는 `④중복`이다. 중복의 대표 행번호는 `제외사유`에 적었다. 전체 상품 카드의 이름·주소와 판정은 [검색 카드별 판정](../momoshop-final-pdp-20261103-51e01084/all_search_card_judgments.csv)을 대조해 작성했다.
공유용 엑셀에서는 내부 후보키와 로컬 증거파일 경로를 뺐다. 원본 판정과 확인 자료는 위 CSV와 [상세 페이지 증거 폴더](../momoshop-final-pdp-20261103-51e01084/pdp_evidence/)에 보존했다.

`제품군`은 검색어가 속한 EY 제품군이다. 실제 상품의 제품군은 [후보 판정 CSV](../momoshop-final-pdp-20261103-51e01084/candidate_judgments.csv)에서 확인할 수 있다. `브랜드`는 대만 경쟁브랜드 판정에 사용한 브랜드만 채웠다. 상품 모델명을 일괄 검증하지 않아 `제품코드`는 비워 뒀고, 검색 응답에 광고 표시를 별도 기록하지 않아 `광고여부`는 빈칸으로 뒀다. 일반 `/product/` 페이지에는 입점 상점 표시가 없어 판매자를 `momo (추정)`, 구분을 `직판 추정`으로 표시했다. `mo店+` 상품은 같은 TP 상점의 대표 상품 페이지에서 확인한 상점명을 `판매자`에 적었다. 일부 제외 행은 판정 순서에 따라 개별 상세 페이지를 열지 않았으므로 페이지 확인 칸이 비어 있다.
공유용 파일의 `출처파일` 열에는 내부 폴더 경로 대신 원본 검색 카드 파일명 `search_cards.csv`만 적었다.

묶음상품의 실제 제품군을 제조사 모델 정보로 확인한 기록은 [최종 모수 판정 설명](../momoshop-final-pdp-20261103-51e01084/README.md)에 있다. 이 확인으로 포함 판정 443행은 바뀌지 않았다.

검증: 저장된 엑셀·CSV를 다시 읽어 v3 원본과 26개 열 이름·순서가 같고, 6,407행·포함 443·제외 5,964·`④중복` 1,420행이 유지됨을 확인했다. 전체 행의 상품명·원본 URL·검색어·판정도 원본 판정 CSV와 대조했다. 처음에는 일반 `/product/` 주소로 열리지 않아 제외한 14개 중 12개가 검색 결과의 원래 주소로는 정상 상품 정보를 보여, 해당 주소로 재판정했다.
