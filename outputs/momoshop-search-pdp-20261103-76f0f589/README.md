# 대만 Momoshop 검색어 기반 PDP 후보 수집 (2026-11-03)

이 폴더는 EY 송부본 `EY_LGE HS 온라인 리테일 클리닉 진단 항목_v2.2_20261023(송부본).xlsx`의 **Search Term** 시트에서 Momoshop 294~308행을 출발점으로 만든 로컬 수집 결과다. J열 검색어를 기본으로 하되 EY 검토 M/N열을 적용해 295·296·297·299행은 제외하고, 294행 `LG 乾衣機`는 `乾衣機`로 바꿨다. 307행은 영어 번역 표기만 문제로 표시돼 J열 `上下門冰箱`을 유지했다. 실제 검색어는 11개다.

검색어별 첫 페이지부터 **서버가 보낸 공개 HTML의 상품 목록(JSON-LD)**을 순서대로 읽어, 최대 1,000카드 또는 마지막 페이지까지 수집했다. 유료 Zyte 호출과 운영 DB·클라우드 쓰기는 하지 않았다. 처음에는 서로 다른 시점의 요청을 비교해 화면 상품과 JSON-LD 목록이 다르다고 잘못 판단했다. 2026-11-03 같은 브라우저 페이지 안에서 `冰箱` 3·84페이지, `乾衣機`·`洗衣機` 첫 페이지의 화면 카드와 JSON-LD를 직접 대조한 결과, 각 페이지의 12개 상품명·주소·순서가 모두 같았다. 별도 요청 사이에 광고 상품이 바뀔 수 있으며, 6,407개 카드 전체를 화면에서 일일이 대조한 것은 아니다. `rank_by_response`는 각 수집 응답의 화면 순서를 나타내는 것으로 표본 검증했다.

## 파일과 상태

- `keywords.json`: 적용·제외 검색어와 원본 엑셀 위치.
- `source-<원본행>.jsonl`: 검색어별 원본 카드, 응답 주소·페이지·순위 포함.
- `search_cards.csv`: 11개 원본 파일을 합친 6,407행.
- `unique_pdp_candidates.csv`: 중복을 합친 2,677개 URL 후보. `review_status`에 후속 확인 필요를 명시했다.
- `summary.json`: 건수·실패 여부·수집 방법.
- `collect.py`: 수집·재개·파일 생성 코드. `--dry-run`으로 검색어만 확인하고, 중단 지점이 있으면 `--resume`으로 이어 받는다.

이 결과는 **검색 원본 후보**다. EY의 `경쟁브랜드` 시트, 냉장고·세탁기·건조기 제품군, 리퍼·리셀·부품, 판매자와 상세 페이지 상태를 적용한 [최종 PDP 모수 443개](../momoshop-final-pdp-20261103-51e01084/README.md)를 별도 폴더에 정리했다. 건조기 브랜드는 기존 PDP 추출 코드의 세탁기 브랜드 준용이라는 AI 해석을 적용했다. Momoshop의 기존 OSM 공유용 v3 모수 파일은 그대로 둔다.
