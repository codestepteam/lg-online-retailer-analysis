## 확정 사항

### 대시보드 계산과 데이터

- **CCR은 항상 다섯 지표의 평균으로 계산한다.** CCR은 Conversion Compliance Rate, 상품 상세 페이지의 콘텐츠 진단 준수율이다. 대상은 Video(영상), Warranty(보증 정보), Dimension(치수 정보), Reviews (Q’ty)(리뷰 수), Reviews (Rating)(리뷰 평점)다. Flixmedia 연동·정상 표시 두 지표는 화면에 보여주되 CCR 평균에서는 제외한다. 개요 화면과 자사 상세 화면에 같은 기준을 적용한다. 회의 초반의 ‘Flixmedia가 있으면 7개 평균’ 설명은 후반에 정정됐다. [전사 57:45~59:13](원본_전사.md#5745-김주성ey)
- **월 마감 후 결과값을 고정한다.** 같은 월의 결과가 조회하는 날짜에 따라 달라지면 안 된다. OSM 데이터의 지연 입력을 고려해 3일의 대기 기간을 두고 월 자료를 마감한다. 진행 중인 월은 선택지에 넣지 않고 마감된 월까지만 조회한다. 일별 자료의 3일 대기 기준도 유지한다. 10월 3일에 9월 자료를 마감·고정하는 예시로 재확인했다. [전사 10:05~10:59](원본_전사.md#1005-김주성ey), [01:11:44~01:13:48](원본_전사.md#011144-speaker-5)
- **Search SOV와 Search Top Rank는 OSM 데이터가 있는 대상부터 원천을 교체한다.** SOV는 Share of Voice, 목록 노출 점유율이다. OSM은 이 회의에서 지칭한 외부 수집 데이터 원천이다. 10월 16일 현재 원천 데이터 접근이 열리지 않았다는 사용자 설명에 따라 당장은 자체 수집 상태를 유지한다. 원래 OSM 데이터가 없는 곳도 자체 수집을 유지한다. OSM 접근 후 데이터 구조를 확인해 교체한다. [전사 38:09~44:19](원본_전사.md#3809-김주성ey), 사용자 메모
- **Category SOV와 Category Top Rank는 자체 수집을 사용한다.** 별도로 확정한 카테고리 상품 목록 URL을 기준으로 수집하며, OSM의 카테고리 URL로 대체하지 않는다. Visibility SOV는 Search SOV와 Category SOV의 단순 평균이다. 일별 자료가 빠진 경우 실제 자료가 있는 날을 기준으로 평균을 낸다. [전사 35:01~40:25](원본_전사.md#3501-김주성ey), [42:28~42:44](원본_전사.md#4228-김주성ey)

### 대시보드 필터와 표시

- **대시보드는 영어로 제공한다.** 화면 문구·지표명·약어는 보유한 Glossary(용어집)를 기준으로 통일하고, 용어집 버튼의 내용뿐 아니라 화면 전체를 대조한다. 인수 문서의 요구사항 체크리스트도 현재 구현과 대조한다. [전사 09:42](원본_전사.md#0942-김주성ey), [17:08~19:25](원본_전사.md#1708-김주성ey)
- **국가에 맞는 리테일러와 제품군만 표시한다.** 회의에서 설명한 대상은 초기 7개국에 영국·독일을 추가한 9개국이다. 스페인은 냉장고·세탁기·식기세척기, 나머지는 냉장고·세탁기를 표시한다. 비대상 식기세척기는 빈 열로 남기지 않고 열과 선택지에서 제외한다. [전사 22:07~22:48](원본_전사.md#2207-김주성ey), [30:40~31:17](원본_전사.md#3040-김주성ey)
- **콘텐츠 진단의 신호등은 80% 이상 초록, 50% 이상 80% 미만 노랑, 50% 미만 빨강이다.** Visibility 같은 목록 노출 지표에는 이 신호등 기준을 적용하지 않는다. [전사 25:15~26:48](원본_전사.md#2515-김주성ey)
- **증감은 모든 화면에서 색상과 화살표를 통일한다.** 상승은 초록색 숫자와 뒤쪽 `↑`, 하락은 빨간색 숫자와 뒤쪽 `↓`를 사용한다. `+`, `-` 부호와 삼각형 표기로 대신하지 않는다. 비율 간 차이는 퍼센트포인트인 `%p`를 유지한다. 예: `8.0%p↓`. 보고서에도 동일하게 적용한다. [전사 19:25~21:40](원본_전사.md#1925-김주성ey), [01:32:54~01:33:16](원본_전사.md#013254-김주성ey)
- **Visibility 추이는 일별·월별과 다섯 지표를 제공한다.** Search SOV, Category SOV, Search Top Rank, Category Top Rank, Visibility SOV를 선택할 수 있게 한다. 일별은 선택한 월 안의 변화, 월별은 최근 6개월 추이다. 그래프 축은 기계적으로 0~100%로 고정하지 않고 실제 값 범위에 맞춘다. LG는 빨간색, 삼성은 파란 계열로 구분하는 방향이다. [전사 42:51~46:50](원본_전사.md#4251-김주성ey), [48:19~48:40](원본_전사.md#4819-장재휴)
- **전년 자료가 없는 전년 대비 값은 비워 둔다.** 자료가 없는데 0이나 임의의 비교값으로 채우지 않는다. [전사 44:26~44:50](원본_전사.md#4426-김주성ey)
- **수정 대상 URL은 하나라도 N 판정이 있는 상품 상세 페이지다.** 모델명과 URL을 함께 표시하고 지난달부터 남은 문제와 새 문제를 구분한다. 신규·지속의 경계 사례는 아래 확인 목록에 남긴다. [전사 23:34~25:00](원본_전사.md#2334-김주성ey)

### 대시보드 경쟁사 비교와 원본 표

- **경쟁사 분석의 Rank Table은 상위 10개 브랜드를 표시하고 LG는 항상 보인다.** 그래프에는 클리닉용 지정 경쟁 브랜드만 표시한다. 표 아래에는 LG의 순위와 SOV를 계속 확인할 수 있는 전용 행을 둔다. LG가 상위 10위 안에 있으면 해당 순위 자리에도 표시한다. 하단 전용 행을 무조건 ‘11위’로 표시해 순위를 오해하게 하지 않는다. [전사 53:19~57:30](원본_전사.md#5319-장재휴)
- **여러 리테일러 선택 시 브랜드별 SOV를 평균낸 뒤 순위를 다시 매긴다.** 리테일러별 순위 숫자를 단순 평균하는 방식은 아니다. [전사 48:42~52:56](원본_전사.md#4842-김주성ey)
- **Conversion Compliance Rate Comparison은 실제 값과 비교값을 구분한다.** 경쟁사의 실제 지표값, LG와의 격차, 그 격차의 전달 대비 변화를 알아보기 쉽게 보여준다. 단순히 격차 숫자만 나열해 경쟁사 실제 값을 역산해야 하는 구조는 개선한다. 구체적인 배치는 개발팀 수정안에 피드백을 받아 정한다. [전사 01:01:45~01:03:58](원본_전사.md#010145-speaker-4)
- **Primary Competitor Analysis의 오각형 그래프와 Conversion Trend 위치를 바꾼다.** Conversion Trend는 위쪽으로, 오각형 그래프는 아래 개별 다섯 지표 비교 표에 대응하는 자리로 옮긴다. [전사 01:06:21~01:06:45](원본_전사.md#010621-장재휴), 사용자 메모
- **경쟁사를 기준으로 보는 지수는 LG ÷ 경쟁사 × 100이다.** 회의에서 ATA라고 부른 비교 지수이며, 100보다 크면 LG가 높은 값이다. 예: LG 81%, 경쟁사 66%이면 약 123이다. 단순 격차 15%p와 구분한다. 순위처럼 낮을수록 좋은 지표의 표시 방향 등 세부는 확인 목록에서 다룬다. [전사 01:04:16~01:05:41](원본_전사.md#010416-김주성ey)
- **원본 표의 From–To는 표시·다운로드할 행의 기간이다.** 계산식을 바꾸는 조건이 아니다. 집계한 표와 URL별 판정 자료를 구분하며, 월별 조회 자료도 마감·고정된 자료를 사용한다. [전사 01:09:07~01:13:35](원본_전사.md#010907-김주성ey)

### 월간 보고서 구성과 문구

- **월간 보고서는 국가별로 만든다.** 프랑스 보고서에는 프랑스에 해당하는 리테일러와 제품군을 모두 보여준다. 7개국이면 국가별 보고서 7개다. 해당 국가의 법인장·담당자 등 수신자의 직급이 달라도 내용은 동일하다. [전사 01:19:08~01:21:28](원본_전사.md#011908-김주성ey)
- **한국어·영어 두 버전을 제공한다.** 대시보드의 영문 전용 정책과 구분한다. 한국어 지표명도 현재 용어집을 따르고, 공간 제약으로 줄일 때는 정식 명칭을 기준으로 줄인다. [전사 01:25:27](원본_전사.md#012527-김주성ey), [01:37:53~01:42:05](원본_전사.md#013753-김주성ey)
- **Overview 아래의 요약은 실질적으로 읽을 가치가 있는 내용으로 만든다.** 사용자 지정 예시인 `FR_2026-08_EN.html`의 요약처럼 수치의 상승·하락을 반복하는 뻔한 문장을 피한다. AI로 초안을 만들 수 있지만 국가 매니저 등을 포함해 사람이 검수한 뒤 최종 배포한다. 구체적인 원인이나 성과는 근거가 있는 범위에서 쓴다. [전사 01:24:23~01:25:16](원본_전사.md#012423-김주성ey), 사용자 메모
- **주요 확인사항은 보고서 내부 상세 구역으로 이동한다.** 각 구역의 Dashboard 버튼은 국가·조회 월 등 해당 조건을 유지해 관련 대시보드로 이동한다. 도착 탭과 나머지 조건의 매핑은 아래 확인 목록에서 정의한다. [전사 01:25:27~01:26:49](원본_전사.md#012527-김주성ey)

### 월간 보고서 우선순위와 정렬

- **월간 보고서의 비교 경쟁사는 삼성으로 고정한다.** 대시보드의 경쟁사 선택 기능과 구분한다. 삼성 자료가 없는 조합의 처리는 추가 확인한다. [전사 01:28:45](원본_전사.md#012845-김주성ey)
- **Primary Competitor by Product는 `Gap vs SS`의 오름차순으로 정렬한다.** SS는 이 표에서 삼성이다. 부호를 포함해 LG가 가장 뒤처진 항목을 위로, 앞선 항목을 아래로 둔다. 격차의 절댓값으로 정렬하지 않는다. **동률이면 영문 지표명의 알파벳순을 유지한다.** 알파벳순은 10월 16일 사용자 후속 확정이다. [전사 01:31:31~01:32:45](원본_전사.md#013131-김주성ey), 사용자 후속 지시
- **제품군별·월별 실제 Gap으로 각각 정렬한다.** 첨부 이미지의 냉장고 순서는 아래와 같다. 아래 숫자는 정렬을 확인하기 위한 부호 있는 값이며, 실제 표시는 화살표 규칙을 따른다.

- **Priority는 리테일러 × 제품군별로 전월 대비 크게 나빠진 진단 항목을 강조한다.** 두 리테일러 × 두 제품군이면 4조합, 스페인처럼 세 제품군이면 6조합이다. 무조건 상위 4건이라는 의미는 아니다. 대상은 회의 말미의 정정에 따라 Visibility를 제외하고 Flixmedia를 포함한 7개 진단 지표다. CCR 평균의 5개와 구분한다. [전사 01:27:17~01:27:51](원본_전사.md#012717-speaker-7), [01:33:33~01:35:45](원본_전사.md#013333-김주성ey)
- **새 과제는 New, 반복되는 과제는 Persistent와 지속 기간으로 구분한다.** 지속 기간은 2개월 이상부터 표시하며 `Persistent·2M`, `Persistent·3M`처럼 대문자 M을 쓴다. `1M`, `2mo`, `2m`은 최종 표시로 사용하지 않는다. [전사 01:35:49~01:37:20](원본_전사.md#013549-김주성ey), 사용자 후속 지시

### 보고서 수신자 관리와 협업

- **국가별 보고서 수신자 목록을 관리할 간단한 화면을 만든다.** 현업 담당자가 국가별로 수신자를 추가·제외할 수 있고, 같은 국가의 수신자에게 같은 보고서가 발송된다. [전사 01:19:46~01:22:19](원본_전사.md#011946-김주성ey)
- **내용 검수 후 Publish로 발송하는 흐름을 갖춘다.** 검수 담당자가 내용을 확인하고 발행하면 그 시점에 등록된 수신자에게 보고서를 보낸다. 외부 서버에서 먼저 간단한 시험용 화면을 구성하는 방향이 논의됐으며, 실제 발송 연계·사내 규정·운영 담당자 승인은 별도 확인 사항이다. [전사 01:22:19~01:24:06](원본_전사.md#012219-김주성ey)
- **Dooray 이슈를 대시보드·보고서·클리닉으로 구분한다.** 태그나 말머리를 붙여 담당자와 의사결정자가 해당 이슈를 찾고 처리할 수 있게 한다. [전사 01:43:34~01:44:28](원본_전사.md#014334-speaker-5)
