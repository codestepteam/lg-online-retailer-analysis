### 데이터 수집/진단 로직 세부 정의

- PDP 모수 확장/수집 경로:

  - OSM 대상: OSM 쿼리 → PDP 추출 → 필터/정규화 → 수집.

  - 비OSM: 국가별 검색어 확인 → 검색 → 리리부 제거 → 브랜드 필터 → 중복 제거(Distinct). 기본은 검색어 기반 수집, 브랜드/카테고리 페이지는 보조 검증용.

  - 결론: 양 경로 모두 마지막 단계에 공통 예외 처리(블랙리스트/필터) 적용.

- Marketplace/Outlet 등 예외 처리:

  - 마켓플레이스, Outlet, 비통제 URL은 URL 패턴(예: ‘outlet’) 또는 UI 필터로 제외. 리테일러별 예외 로직과 블랙리스트 관리 필요.

  - OSM 대상에서도 Marketplace 혼입 가능성 고려, OSM/검색어 기반 모두 공통 예외 처리 로직 적용.

  - 대시보드 집계에서는 PDP URL 중 진단 대상이 아닌 경우 행 삭제 대신 별도 컬럼로 구분하여 성적표/스코어링에서 제외.

- 판정 불가 기준:

  - 리테일러/환경 차이로 특정 항목 판정 불가(예: 동영상 미지원) 시 ‘N’이 아닌 ‘판정 불가’로 처리, 분모에서 제외.

- USP/Alt Text 진단 범위:

  - USP는 Eyebrow 외 상단 ‘Key Feature’ 텍스트 영역 포함. 키워드 매칭은 특수문자/띄어쓰기 보정 가능한 유사도 기준 적용.

  - PDP Alt Text는 ‘갤러리 영역’ 한정. BCP Alt Text는 히어로 배너/카테고리 내비/USP 3구간만 진단하며, 모수 적어 자동화+수기(ITM) 병행 고려.

- 진단 ID 42(Flix360 HTML) 항목은 현시점 코드 유무 확인 유지, 변별력/렌더링 이슈 고려해 기준 변경 내부 논의 중.

- 엑셀 로우데이터 다운로드는 대시보드 필터와 무관하게 전체 원본 데이터 포함 유지.
