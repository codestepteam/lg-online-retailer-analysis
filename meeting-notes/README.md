# 회의록 보관

프로젝트 회의 자료는 이 폴더 아래에 회의 날짜별로 보관한다. 날짜 폴더는 저장일이 아닌 원문에 표시된 회의일을 사용한다.

```text
meeting-notes/
  YYYY-MM-DD/
    원본_전사.md
    원본_요약.md
    회의_정리.md
```

- `원본_전사.md`: 공유 자료의 전사문을 화자·시각과 함께 보존한다. 원음 파일과는 구분한다.
- `원본_요약.md`: Plaud 등 출처 서비스가 제공한 요약을 보존한다.
- `회의_정리.md`: 핵심 내용·회의 중 합의·후속 할 일·미확정 사항을 별도로 정리한다.

원문 내용은 교정하지 않고, 해석이나 확인할 사항은 별도 정리에 적는다. 같은 날 여러 회의가 있으면 파일 이름 앞에 시각이나 회의명을 붙여 구분한다. 회의 발언·서비스의 AI 권장사항·현재 구현 완료 여부를 구분하며, 회의 자료를 저장한 것만으로 프로젝트의 기존 사용자 결정이나 코드를 변경하지 않는다.
