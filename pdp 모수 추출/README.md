정리일: 2026-10-25. 담당: 이승희.
근거: 두레이 "모수" 태그 과제 9건, 진단 항목 엑셀 v2.2, 10-13 회의 전사.
표시: **[확인]** 원문으로 확인한 사실. **[추정]** 해석·추정. **[미정]** 아직 정해지지 않음.

## 1. 이 작업이 무엇인가

- PDP는 리테일러 사이트의 상품 상세 페이지다.
- 모수는 진단할 PDP URL 목록이다.
- PDP 모수 추출은 국가·리테일러별로 진단할 PDP URL 목록을 만드는 일이다.
- 이 작업의 담당자는 이승희다. [확인] 두레이 #42·#121
- 같은 방식으로 PLP 모수는 박정환, BCP 모수는 김재훈이 맡는다. [확인] 두레이 #42
- 장재휴의 최신 지시는 "업데이트된 Search Term 보고 PDP 모수 URL 뽑기 진행"이다. [확인] 두레이 #121

## 2. 기준 자료

- 기준 엑셀은 `관련문서/EY_LGE HS 온라인 리테일 클리닉 진단 항목_v2.2_20261023(송부본).xlsx`이다.
- v2.2는 2026-10-23 최하은(EY)이 보냈다. [확인] 두레이 #121
- 검색어는 v2.2의 `Search Term` 시트에 있다.
- 10-23 변경 검색어는 `Search Term` 시트 O열(상세 설명)에 적혀 있다. [확인] 두레이 #121

- 리/리/부 판별 키워드는 v2.2의 `제외키워드(리리부)` 시트에 있다.
- 대상 국가·리테일러와 OSM 보유 여부는 `대상 국가,리테일러` 시트에 있다.

- `OSM_미보유_..._20261006.xlsx`는 v2.0 기반 옛 가공본이라 지웠다. 쓰지 않는다.

## 4. 처리 순서

1. 대상 목록을 만든다. OSM에서 가져오거나 검색어로 검색해서 만든다.
2. 대상 브랜드만 남긴다(브랜드 거르기).
3. 리/리/부를 뺀다.
4. 리테일러별 제외 목록을 뺀다.
5. 실제 URL 기준으로 중복을 없앤다.

- 2번과 3번 중 무엇을 먼저 할지는 정해지지 않았다. [미정]
- 10-13 회의에서 의견이 갈렸다. 한쪽은 브랜드 먼저, 다른 쪽은 리/리/부 먼저였다. [확인] 회의 전사
- 순서가 달라도 최종 결과는 같아야 한다. [추정]
- 순서는 "어느 단계에서 몇 개가 빠졌나"를 셀 때만 영향을 준다. [추정]
- 5번은 리/리/부 제외 다음에 한다. [확인] 두레이 #119
- 마켓플레이스는 리/리/부의 "리셀"에 속한다. 찾는 방법이 달라 단계는 나눈다.
- 국가별 조사 제품군 필터를 적용한다. 냉장고·세탁기·세탁건조기·건조기만 남기고 스타일러는 뺀다. [확인] 사용자 결정 D052 (D047 대체)
- 검색어의 세부 유형(문 구조·폭 등)과 맞는지는 거르지 않는다. 실제 URL 중복 제거로 정리한다. [확인] D052
- 묶음 상품은 포함한다. 대상 제품이 하나라도 들어 있으면 남긴다. [확인] D052
- 식기세척기를 스페인만 넣을지 다른 나라도 넣을지는 추후 확인한다. [미정]

## 6. 리/리/부 제외

- 리/리/부는 리퍼비시·리셀·부품이다.
- 리퍼비시는 수리·재생 상품이다.
- 리셀은 리테일러 직판이 아닌 외부 판매자(마켓플레이스) 상품이다.
- 부품은 본체가 아닌 부속품이다.
- 리퍼비시는 대개 상품명에 단어가 드러난다.
- 리셀은 상품명이 신품과 같아서 판매자 정보로 가려야 한다.
- 두레이 #42의 "판매자 기반"은 판매자 정보로 리셀을 거르라는 뜻이다. [추정]
- 제외한 URL은 지우지 않고 제외 사유와 함께 남긴다. [확인] `lg-pipeline` LGOP-053
- 10-14 기준 팀 파이프라인 모수 단계에는 리/리/부 제외가 없었다. [확인] LGOP-053

- outlet은 반품·전시 상품을 할인해 파는 코너다. [추정]

### 체코 Alza

- 법인이 준 제외 URL은 25개다. [확인] 두레이 #60
- 25개 모두 URL에 `-bazar-`, `-sleva-`, `-levne-` 중 하나가 있다. [확인]
- 개수는 bazar 9, sleva 10, levne 6이다. [확인]
- bazar는 중고·반품 상품이다. [추정]
- sleva는 "할인", levně는 "싸게"라는 뜻이다.
- sleva·levne가 개봉·포장 훼손 할인품인지는 확인하지 못했다. [미정]
- 이 세 단어를 일반 규칙으로 써도 되는지는 확인이 필요하다. [미정]
- 체코 Datart의 제외 URL은 받은 것이 없다. [확인]
- `제외키워드(리리부)` 체코 목록에는 bazar·sleva·levne가 없다. [확인]
- 그래서 시트 키워드만으로는 Alza 25개가 걸러지지 않는다. [확인]

## 8. 중복 제거

- 중복 제거는 실제 URL 기준이다. [확인] 두레이 #119
- 요청 URL은 수집할 때 넣은 주소다.
- 실제 URL은 리다이렉트(자동 이동) 후 도착한 주소다.
- 실제 URL이 같은 요청 URL이 여러 개면 1개만 남긴다. [확인]
- 요청 URL과 실제 URL이 달라도 실제 URL이 겹치지 않으면 남긴다. [확인]
- 기준은 "요청 = 실제"가 아니라 "실제 URL 기준으로 하나씩"이다. [확인]
- 10-14 기준 팀 파이프라인은 정확히 같은 URL만 중복으로 봤다. [확인] LGOP-053
