# PDP 모수 CSV 4개 파일의 차이

확인일: 2026-10-30. PDP는 상품 상세 페이지이고, 모수는 이번 진단 대상이 되는 상품 주소 목록이다.
이 폴더 바로 아래의 CSV 4개를 전수 비교했다. 아래 행 수는 머리글을 제외한 데이터 행 수이며, 제외·확인 필요 행도 전체 행에 포함한다.

**v1은 이전 전달본, v2는 내용을 정정한 전체판정본, 공유용은 v2와 같은 상품 목록·판정을 읽기 쉽게 표현한 파일이다.**
v1을 두레이 드라이브에 올렸던 파일이라는 설명과 v1·v2 명명은 사용자 확인에 따른다. 이번 작업에서 드라이브 원격 파일을 다시 조회한 것은 아니다.

### 포함에서 제외로 바뀐 Darty 5개

| CSV의 행번호 | 상품명 | v1 판정 | v2 판정 | 정정 이유 |

외부 판매자 4개는 원본 주소의 `?ofmp=`라는 판매 제안 식별 부분을 포함해 재확인한 결과다. 이전 수집에서는 이 부분이 없는 주소로 이동해 Darty 직판으로 기록돼 있었다. 판매 종료 상품은 판매자 확인 불가·페이지 상태 영구품절로 정정했다. 이번에는 저장된 CSV와 당시 검증 기록을 비교했으며 현재 판매 화면을 새로 확인한 것은 아니다.

### 왜 “기존 파일이 5개 더 많다”는 말이 나오는가

- 포함 대상: **v1의 9,763개 − Darty 정정 5개 − 카테고리 재확인 41개 = v2의 9,717개**.
- 전체 행: **v1의 56,071행 − 이미 제외였던 과거 목록 74행 = v2의 55,997행**.
- 제외 행: **v1의 46,072행 − 과거 목록 74행 + Darty 정정 5행 + 카테고리 재확인 41행 = v2의 46,044행**.

따라서 v1이 공유용보다 포함 대상이 46개 많다(10-29 공유 당시에는 Darty 5개 차이였고, 10-30 카테고리 재확인으로 41개가 더 빠졌다). “파일의 나머지 내용까지 전부 같다”는 뜻은 아니다. v2의 포함 URL 9,717개는 모두 v1에도 포함돼 있었으며 새로 포함된 URL은 없다.

## 3. v2 → 공유용: 목록·판정은 같고 표현·열 구성이 다름

**55,997행의 순서·상품 주소·포함/제외/검토 필요 판정은 모두 같다.** v2와 공유용은 같은 수정 결과를 담는다.

### 열 이름과 판정 표현

| v2 | 공유용 |
| --- | --- |
| URL | 확인 요청 URL |
| 원본URL | 원본 상품 URL |
| 실제URL | 접속 후 URL |
| 판정 | 모수 포함 여부 |
| 페이지상태 | 페이지 접속 확인 결과 |
| 남김 | 포함 |
| 확인 필요 | 검토 필요 |
| 제외 | 제외 |

공유용에서는 내부 관리용 `OSM_RK`·`OSM_SOURCE_TYPE` 2열을 뺐다. `페이지확인규칙`은 유지한다. OSM은 원본 상품 목록을 제공한 외부 데이터의 출처 이름이며, 위 두 열을 빼도 상품 목록·판정은 바뀌지 않는다.

### 메모·판매자근거의 표현 정리

열 이름과 판정 표현을 대응시킨 뒤 비교하면 **1,655행의 1,663셀**이 추가로 다르다. 모두 `메모`·`판매자근거`의 아래 표현 변경이며, 그 밖의 공통 열 값은 같다.

| v2 표현 | 공유용 표현 |
| --- | --- |
| Codex 내부 브라우저 | 브라우저 |
| Codex 화면 | 수집한 상품 화면 |
| Codex에서 상품을 열지 못함 | 브라우저에서 상품을 열지 못함 |
| 부품 의심 단어(시트 밖, AI 추가) | 부품 의심 단어(공식 제외키워드 외 추가 검토) |

`판매자근거` 1,556셀, `메모` 107셀이 바뀌었다. 8행은 두 열이 모두 바뀌어 셀 수와 행 수가 다르다. 상품명·URL에 들어 있는 제품 기능명 AI, 사용자 결정 표시와 미확인·추정 표시는 유지한다.

## 4. 어떤 파일을 보면 되는가

- 이전 전달 내용과 변경 이력을 비교할 때: **v1과 v2**.
- 수정 결과를 내부 열까지 확인할 때: **v2**.
- EY·LG에 읽기 쉬운 형태로 전달할 때: **공유용**. v1 대비 포함 대상 46개 감소와 별도 정보 정정이 반영돼 있다.

## 5. 근거와 검증 방법

파일 역할은 사용자 설명, 건수·차이는 이 폴더의 CSV 4개 전수 대조에 근거한다. 행은 CSV 안의 `행번호`로 대응시키고, 주소·판정·공통 열의 모든 셀을 비교했다. 원본 CSV는 수정하지 않았다.

- 변경 배경: [연구 결정 기록](../../docs/DECISIONS.md)의 D072(공유용), D073(과거 목록 제거), D075(Darty), D078(Lazada), D079(중복), D080(표현 정리), D081(v1·v2 명명).
- Darty 정정 당시의 근거: [상품별 수정 전후·검증 기록](../조사_20261029_darty_c9906dc4/정정_1f5465cf/verification.json).
- 이번 비교: [검증 스크립트](../../outputs/pdp-version-comparison-20261030-a5cabba9/verify.py), [파일 해시·건수·차이 검증 결과](../../outputs/pdp-version-comparison-20261030-a5cabba9/verification.json).

저장소 루트에서 재확인하는 명령:

```sh

```

스크립트는 실제 CSV 4개, 이 문서의 요약 표·링크 및 가짜 입력의 차이 검출을 확인한다. 비교 시점의 각 파일 해시(파일 내용 식별값)는 검증 결과에 보존한다.

## 6. 공유용 → 공유용 v2: 브랜드·제품코드 열 추가 (2026-10-30)

EY 최하은님 피드백: 공유용의 `OSM브랜드`(F열)는 OSM 행에만 값이 있어서, LG로 거르면 OSM이 없는 국가(검색으로 수집한 10개국 12개 리테일러)가 빠지고 제품코드도 없었다.
**기존 24열은 모든 셀이 그대로이고(`OSM브랜드` 포함), `제품군` 바로 뒤에 `브랜드`, `제품코드` 2열을 넣었다.** LG만 보려면 `브랜드`를 LG로 거르면 된다.

| 새 열 | OSM 행(12,126) | 검색 행(43,871) |
| --- | --- | --- |
| 브랜드 | OSM `BRAND`(대문자) | 그 상품의 실제 브랜드. 저장된 상품 페이지가 있으면 페이지의 브랜드, 없으면 상품명·주소에서 찾음. 대상 브랜드가 아니라서 제외된 상품도 그 상품의 브랜드를 씀 |
| 제품코드 | OSM `MPC`(대문자). `MPC`가 빈 행은 `MODEL_DEDUP_KEY` | 저장된 페이지가 있으면 페이지의 모델 번호(리테일러마다 읽는 칸이 다름), 없으면 상품명에서 찾음. 못 찾으면 빈칸 |

- 브랜드=LG 이고 포함인 행: 2,205행(OSM 1,361 + 검색 844). 검색 10개국 모두 잡힌다.
- 빈칸: OSM 행은 0. 검색 포함 4,095행은 브랜드 0, 제품코드 2(반자동 세탁기, 상품명·페이지에 모델 번호가 없는 Falabella 1행). 검색 제외 39,750행은 브랜드 4,081, 제품코드 8,216(정수기 필터 1행 포함, 페이지가 없고 상품명에도 없는 행).
- Whirlpool·Siera 모델은 제조사 표기대로 띄어쓰기가 있어(예: `FFWD 9248 WBS V NA`) 적힌 그대로 두었다. 묶음 상품은 `A + B`로 적었다.
- 페이지의 모델 번호는 지역 꼬리가 붙어 상품명과 다를 수 있다(예: `RB38C603CWW/EF`, `GMBS30SDEP.AEPQEUZ`). 포함 행 중 제품코드가 상품명에 그대로 들어 있는 비율은 리테일러별로 87~100%다.
- 행마다 값을 어디서 찾았는지(페이지/상품명/수동 확인)는 공유 파일에 넣지 않고 [근거 CSV](../../outputs/pdp-share-v2-20261030-94e9c3b7/브랜드_제품코드_근거.csv)에 남겼다.

```sh
cd outputs/pdp-share-v2-20261030-94e9c3b7
/usr/bin/python3 build_share_v2.py   # 공유용 v2 생성
/usr/bin/python3 verify.py           # 기존 24열 전 셀 비교, 열 위치, 가짜 입력 검출, 빈칸·LG 건수표
```

[생성 스크립트](../../outputs/pdp-share-v2-20261030-94e9c3b7/build_share_v2.py), [검증 스크립트](../../outputs/pdp-share-v2-20261030-94e9c3b7/verify.py), 리테일러별 추출 결과는 같은 폴더의 `parts/`, 추출 스크립트는 `parts_scripts/`.
