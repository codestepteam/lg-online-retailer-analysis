### 현재 Brand Page·BCP 검증 범위와 원문 확인

D012에 따라 1차 테스트의 페이지 유형별 수집 범위는 다음과 같다. 일반 Brand Page는 ID8·9·10만 수집하고, Brand Category Page는 ID8·9·10·23·18·19·20·21·22를 모두 수집한다. ID18~23을 Brand Page에 적용하지 않는다. ID7은 BCP 도달 경로를 다루지만 F15는 Home이므로 이번 페이지 본문 수집 범위와 구분한다. [상세 안내](BCP_POC.md)

- ID9는 Title·Meta Description·H1·Robots Meta를 모두 확인하며, T17은 Robots를 `index, follow`로 명시한다. ID10 T18은 canonical 태그 포함 여부다. PDP의 ID13 정상 도착 규칙을 자동으로 추가하지 않는다.
- 스크롤·더보기 중 주소가 `?page=3/4`로 바뀌는 MediaMarkt ES·NL, MediaWorld에서는 최종 화면의 `noindex,follow`를 처음 요청한 BCP의 ID9 값으로 쓰지 않는다. 2026-09-28 재수집은 스크롤 전에 처음 요청한 URL과 메타데이터·Canonical을 저장했고, 세 곳 모두 초기 Robots Meta가 `index, follow`였다. [재수집 판정 결과](../1차%20테스트/bcp-zyte-poc/results/20260928T060234KST/판정_1차_요약.md)
- ID21 T27/W27은 원본 페이지의 제품군 Navigator와 클릭 가능한 카드·CTA의 존재, 그 카드를 실제 눌렀을 때 해당 제품군의 상품 목록을 탐색할 수 있는 페이지로 가는지를 요구한다. 도착 화면의 H1 태그 자체는 필수 조건이 아니다. 카드와 도착 목록의 의미 관계는 Jev 시험 판단을 사용할 수 있지만 클릭·수집 성공 여부는 별도 근거로 확인한다(D024). ID22 T28/W28은 PDP로 이동 가능한 제품 카드/CTA를 요구한다. 정적 이미지나 링크 문자열만으로 작동을 검증했다고 하지 않는다.
- ID23 T19/W19는 브랜드·카테고리 관련 질문–답변이 구조화된 **텍스트**로 존재하는지 확인한다. 이미지로만 된 FAQ는 N이며 JSON-LD 필수 조건은 이 셀들에 없다.
- ID20 T26에는 모델별 USP 자료를 받은 뒤 노출할 핵심 USP 블록을 지정할 필요가 적혀 있다. BCP 9개 전체를 LG.com과 일치 비교하는 규칙은 아니다. 명시적 닷컴 대비 USP 반영률은 PDP의 ID45(L36/T36/W36)다.
- S04 `BCP!B4`는 표준 구성 7개 중 2개 이상 또는 `Controlability`가 있으면 BCP가 있다고 보는 조건을 제시한다. 운영상 수정 가능성의 증거와 승인 주체는 미확인이다. URL 모양·상품 목록 존재만으로 대상 여부를 확정하지 않는다.
- S04 Y16:Y18은 Crawling Data=Y, Y19/Y24:Y28은 N이다. S05 `ID18_19_20_21_22_23!B4`는 Eye-Check Raw Data로 표시한다. 자동화 가능 여부의 확정 판정이 아니라 원본의 수집 분류이며, 기존 자동 판정 코드가 있다는 증거도 아니다.

S02는 리퍼비시·리셀·부품과 중복 URL을 제외하고, OSM 데이터 보유 리테일러는 OSM URL 목록을 활용한다고 설명한다. S06 세션 2·3·8에는 상위 N개 제한의 적용 순서, 제외 키워드 매칭, 모델 중복 제거 기준을 묻는 질문이 있다. **제외 필요성은 문서에 있지만, 엔진의 실제 처리 순서는 아직 검증하지 않았다.**

일반적인 비중 지표를 구현할 때는 다음을 항목별로 확정한다. 모든 항목에 동일한 분모를 강제하는 공통 계산식은 아니다.

```text
평가 단위 → 대상 조건 → 제외 조건 → 유효 판정 → 분자/분모 → 상위 집계
```

- 대상이 국가·리테일러·브랜드·제품군 중 어떤 조합에 속하는지 확인한다.
- URL·SKU·모델·이미지·검색어를 같은 단위로 간주하지 않는다.
- 비대상, 미수집, 오류, 판정 불가가 분모에 포함되는지 별도 기록한다.
- 주기와 기준일이 같은 데이터끼리 비교한다. S02 검색 지표는 최근 30일 평균, 리뷰 지표는 최신값, 다수 Monthly 지표는 매월 1일 기준으로 기술돼 있다. 실제 운영 기준일은 S06 세션 7에서 확인 대상으로 남아 있다.
- `판정=유지`가 이미 있다면, 앞 단계에서 어떤 제외를 거쳤는지 확인한다. 집계 시점에서 필터링이 없다고 전체 과정에 제외가 없었던 것은 아니다.

**집계 차이를 설명하기 위한 예시**: 한 PDP가 이미지 1개 중 1개 충족, 다른 PDP가 10개 중 0개 충족이면 SKU별 비율의 단순 평균은 50%, 전체 이미지를 합친 비율은 약 9.09%다. 이 예시는 실데이터가 아니라 계산 방식의 차이를 보여 준다.

## 2026-10-12 OSM URL 파생 파일의 제품군 필터

**2026-10-13 후속 결정 D036·D037:** 아래 145행 파일은 기존 행 제거 방식의 작업 이력이다. 사용자의 작성 지시에 따라 원본 이름 뒤에 `_수집url_수정본`을 붙인 [이력 관리 엑셀](SOURCES.md#행-보존-수정본--d036)을 작성했다. 원본 `수집 URL` 1,489행의 내용·순서·기존 셀 서식을 모두 보존하고 카테고리·제외 여부·제외 사유를 추가했다. 후속 D037에 따라 추가 열을 카테고리 코드·제외 여부·제외 사유 세 개로 간소화하고 `제외 여부=N` 145행, `Y` 1,344행으로 표기했다. Y는 제외, N은 수집 대상이다. 제품군 대상 조건은 D033을 유지한다. 처음 추가했던 OSM 포함 여부·URL 수·참고 메모와 카테고리 명칭·세부 구분·확인 상태·근거 열은 사용자의 지시로 삭제했다. 원본에 있는 URL의 제외는 Y로 표시하며, 원본에 없는 URL은 행을 임의로 생성하지 않는다.

수정본에서 REF는 냉장고, WM은 세탁기·세탁건조기, DRYER는 건조기, DW는 식기세척기를 뜻한다. DRYER 및 비대상 제품군의 추가 코드, 열 배치는 AI의 구현 선택이며 프로젝트 전체의 코드 표준 확정이 아니다. 카테고리는 URL 제품명·원본 `수집 URL(과거)`·페이지 제목·외부 분류자료를 구분해 근거 JSON에 기록했다. 확정하지 못한 114행의 코드는 `UNKNOWN`으로 남겼고, 수집 대상으로 선정한 145행에는 미확인 카테고리가 없다. D037 이후 엑셀에는 별도 명칭·확인 상태·근거 열이 없다. 이 분류 작업은 URL별 수집 성공이나 진단 점수를 검증한 것이 아니다.

D033은 이번 URL 목록에만 적용한다. `OSM_수집URL_진단대상35개_제품군필터_20261012.xlsx`의 `수집 URL` 시트에는 스페인 ECI·MediaMarkt의 냉장고·세탁 제품군·식기세척기 URL을, 나머지 국가·리테일러의 냉장고·세탁 제품군 URL을 남긴다. 세탁 제품군은 사용자 확인에 따라 세탁기·세탁건조기·건조기를 포함하고 스타일러는 제외한다. 카테고리 자체에 속하는 브랜드별·세부 유형별 URL은 유지하고, 액세서리 전용 페이지는 제외한다. 카테고리 분류는 원본 `수집 URL(과거)`의 동일 URL 카테고리, URL의 제품명, 코드 URL의 외부 분류 근거를 대조한다. [파일과 출처](SOURCES.md#제품군-추가-필터본--d033).

최종 145행은 냉장고 44행, 세탁기·세탁건조기 67행, 건조기 32행, 식기세척기 2행이다. 474행 리테일러 필터본과 OSM 원본은 보존한다. URL 문자열·원래 순서·서식·다른 시트는 유지하며 중복 제거·URL 교정·실제 수집·점수 집계는 수행하지 않는다. 이는 프로젝트 전체의 제품군 정의나 수집 모수를 소급 변경하는 결정이 아니다.

### 2026-09-28 1차 BCP 판정에 확정한 부분

D017에 따라 ID8 이미지 순위는 화면 표시 면적을 사용한다. D019에 따라 BCP 본문 HTML `<img>`와 제품 카드 이미지를 포함하고 CSS 배경·순수 장식 이미지는 제외한다. ### 추가로 확인할 충돌

- **Q12·Q18 후속:** 세 영역·Alt 존재 여부 기준의 후속 기록은 찾았다. CSS 배경 처리, 원본 정의서 수정·승인 이력, 회차별 실제 재채점 적용 범위는 여전히 구분해 확인한다.
- **Q19 후속:** 파이프라인 선언문 LGOP-058에는 S13의 ID8·ID12를 10월 파이프라인 값으로 교체해 8월 결과로 사용한다고 기록돼 있다. 보고용 선언문 ID12-003에는 이전 결과·코드 버전 대조도 있다. 이는 ‘전체 조사일 미확인’ 중 두 탭에 관한 후속 근거이며, 나머지 탭까지 같은 시점·같은 생성 경로라는 뜻은 아니다. 이번에는 원천 DB 이력을 재조회하지 않았다.
- **Q20 — 집계 범위 혼용:** LG Clinic 회차 비교의 점수·분모 제외 규칙, 보고용 정기 모니터링의 분모, 8월 엑셀 전용 집계가 서로 다르다. [파이프라인 단어집 ‘분모에서 제외’](../../lg-pipeline/knowledge/glossary.md), [보고용 지표 명세](../../lge-hs-clinic-dashboard/spec/metrics.md), 위 8월 코드의 적용 회차를 먼저 확인한다.
- **Q21 — 월 마감 요구와 구현:** D040의 마감 후 고정 요구와 달리 [관리자 구현 문서](../../lge-hs-clinic-dashboard/docs/reporting/admin-console.md)에는 월 마감 잠금이 아직 없다고 적혀 있다. 노출 설정 탭도 10월 22일 ‘개발 중’이다. 회의 합의를 운영 구현 완료로 설명하지 않는다.

## 대시보드 설계에 적용할 제안

다음은 위 자료를 바탕으로 한 설계 제안이다. 승인된 화면 명세나 기존 시스템의 기능 목록은 아니다.

- 수치와 함께 단위, 기간, 대상 수, 유효 판정 수, 정의 버전을 확인할 수 있게 한다.
- 원시 측정값, 환산 점수, 표시 백분율을 구분한다. 예를 들어 0.9라는 저장값이 90%인지 0.9점인지는 지표 정의에 따른다.
- 실측·수기 입력·정책상 간주값의 근거를 구분한다.
- 동일 모수·동일 기준으로 비교했는지 밝히고, 수집 대상이 바뀐 경우 변화량을 해석할 때 알린다.
- 모델이 생성한 인사이트에는 사용한 집계와 근거를 연결한다. 근거 없는 원인 추정이나 성과 보장을 넣지 않는다.

### 2026-09-28 후속 판정 조건 — D018

사용자 수정 요청과 [판정 기준 검토표](../1차%20테스트/BCP_9개_항목_판정기준_검토표.md)를 기준으로 다음 조건을 적용한다. 기존 초안과 충돌하면 이 후속 조건이 우선한다.

- ID8: 이미지 자체의 `alt` 속성만 설명으로 인정한다. CSS 배경 주변 제목·문구로 대체하지 않는다. D019에 따라 제품 카드 이미지는 포함하고 CSS 배경·순수 장식 이미지는 제외한다. 빈 alt만으로 장식 이미지를 단정하지 않는다. 중복 이미지 요소와 대상 0개의 처리만 별도 미결이다.
- ID18: 상단 위치 필수. 텍스트 전용 소개는 N.
- ID19: 단순 브랜드 소개는 N. 브랜드 선택 이유·차별성 설명이 필요하다.
- ID20: 정상 수집한 내용을 확인한 뒤 USP인지 애매하면 N. 이유를 ‘USP 여부 불명확’으로 저장한다. 수집 실패와 추출 누락을 이 정책으로 N 처리하지 않는다.
- ID21: 평가 대상 Navigator 링크 모두 정상 이동해야 Y. 일부 실제 실패는 N이고 미검사 상태는 Y가 아니다.
- ID22: 추천 상품 한 개도 인정하지만, 평가 대상 상품 상세 이동 링크가 모두 정상이어야 Y. 일부 실제 실패는 N이다. 이전 초안의 ‘정상 하나 이상이면 Y’는 대체됐다.
- ID23: 사용자 ‘인정해’를 질문·답변 한 쌍과 질문형 제품 설명(대응 답변 있음) 인정으로 해석했다. 본문 내 텍스트·브랜드/제품군 관련성·열람 가능성 조건을 유지한다.

ID9·10은 D018에서 변경하지 않았다. 이후 D019에 따른 ID8 이미지 범위와 D018의 실제 alt 속성 기준은 [9개 대표 페이지의 1차 판정](../1차%20테스트/bcp-zyte-poc/results/20260928T060234KST/판정_1차_요약.md)에 적용했다. ID18~23 조건은 아직 판정 코드에 적용하지 않았다.
