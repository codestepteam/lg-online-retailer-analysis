BCP에서 실제로 보는 것

파서가 페이지 요소를 찾고, 평가기가 9개 항목을 채점합니다.

  • ID 08–10: 이미지 대체 텍스트, 메타데이터, 대표 URL
  • ID 18–23: Hero, Why LG, USP, 카테고리 이동, 제품 목록, FAQ
  • 리테일러마다 HTML 구조가 달라 Amazon, MediaMarkt 등 사이트별 파서가 따로 있습니다.

확인 수준

구조는 직접 확인, 세부 점수 동작은 일부 재검증이 필요합니다.

Airflow의 실행 순서와 BCP 함수 목록은 이미지 내부 코드에서 확인했습니다. 다만 전달 문서에 적힌 함수 실행 결과는 이번 분석에서 다시 실행하지 않았고, 공식 진단 기준과 다른 것으로 보이는 판정도 있습니다.

한 줄 해석: 기존 엔진은 “페이지를 이해하는 AI”라기보다, 사이트별로 정해 둔 위치에서 정보를 찾고 체크리스트로 채점하는 자동 검사기에 가깝습니다.
