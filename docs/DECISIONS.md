3. **ID19:** 단순 브랜드 소개는 인정하지 않는다. 브랜드를 선택할 이유·차별성이 필요하다. 근거: “단순브랜드 소개는 안돼”.
4. **ID20:** 정상 수집한 내용을 확인한 뒤에도 USP 인정 여부가 애매하면 N으로 판정한다. N 이유에 ‘USP 여부 불명확’을 남겨 명백한 부재와 구별한다. 근거: “애매하면 n으로 해”. 수집 실패·차단·추출 누락을 콘텐츠 부재로 바꾸는 결정은 아니다.
5. **ID21:** 평가 대상 Navigator 링크가 모두 정상 이동해야 Y다. 일부 실제 실패는 N, 미검사는 Y 근거가 될 수 없다. 근거: “모든게 정상이동해야 Y로 인정해”.
