## 확인한 사실

기존 브라우저 관찰에서 동일 상품 ID 4000416185의 영어 주소는 langId=-24, 불어 주소는 langId=-25였다. 쿼리스트링도 URL의 일부이므로 두 주소는 경로가 같아도 전체 URL은 다르다. 따라서 사용자 질문의 의미인 언어별 주소로 접근 가능한 페이지 관점에서는 영어·불어 페이지가 각각 제공된다고 설명한다. 앞선 채팅의 같은 URL·독립된 페이지가 아니다라는 표현은 동일 상품/동일 경로와 동일 전체 URL을 혼동한 부정확한 설명이므로 정정한다. 이 정정은 새 실시간 접속 관찰이나 사용자 운영 결정이 아니다.

근거: [기존 영어 관찰](4929665c6d0a6a40d3a0d8aa9a20c952-assets/en-dom.json), [기존 불어 관찰](4929665c6d0a6a40d3a0d8aa9a20c952-assets/fr-dom.json). 사용자 재질문: langId를 다르게 하면 불어 페이지로 넘어가니까 다른 페이지가 별도로 존재하는 것 아니냐. 답: URL별 언어 페이지라는 의미에서는 맞음.

## 미확인

영어·불어 콘텐츠의 내부 저장 구조와 번역 제작 방식은 계속 미확인이다. 언어별 페이지의 외부 제공 여부와 내부 저장 구조를 별개로 설명한다. OSM 및 전체 SKU 구성은 이번에도 확인하지 않았다.
