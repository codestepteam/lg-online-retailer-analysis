# Coolblue LG 냉장고: Jev 소량 시험 비교

2026-09-28. 대상은 [Coolblue LG 냉장고 BCP](https://www.coolblue.nl/koelkasten/lg)의 **저장된 2026-09-26 HTML**에서 선택한 다섯 본문 영역이다. [선별 검토 메모](../20260927T213640809482Z/선별_검토.md)는 사람이 비교할 사례를 정리한 AI 의견이며 검증된 정답표는 아니다. [첫 응답](../20260927T224810926657Z/responses.jsonl)과 [질문을 구체화한 뒤의 응답](responses.jsonl)은 실제 TypeSafe Jev `jev-1.13.0` API 호출 결과다. 각 실행은 **5건의 요청**이며 한 요청이 ID19·ID20·ID23 질문 세 개에 답했다.

| 영역 | 저장된 문장의 성격 | ID19 Why LG: 1차 → 2차 | ID20 핵심 기술·장점: 1차 → 2차 | ID23 질문·답변: 1차 → 2차 |
| --- | --- | --- | --- | --- |
| `block-00005` | LG 냉장고 소개와 Fresh Converter·절전 설명 | 해당 → 해당 | 해당 → 해당 | 해당(확신도 0.27) → 해당(0.48) |
| `block-00007` | 개별 모델 상품 카드 | **해당 → 비해당** | 비해당 → 비해당 | 비해당 → 비해당 |
| `block-00011` | No Frost·DoorCooling·신선 보관 기술 설명 | 해당 → 해당 | 해당 → 해당 | 해당 → 해당 |
| `block-00013` | Coolblue 배송·설치 안내 | 비해당 → 비해당 | **해당 → 비해당** | 비해당 → 비해당 |
| `block-00016` | 질문 제목만 있고 답은 외부 도움말에 있음 | 비해당 → 비해당 | 비해당 → 비해당(확신도 0.20) | 비해당 → 비해당 |

‘해당’은 Jev가 반환한 `matches`, ‘비해당’은 `does_not_match`다. 위 표는 **본문 영역 분류**이며 페이지 전체 진단 Y/N이 아니다. `responses.jsonl`에는 각 선택지의 확률, 확신도, 모델 이름과 사용 토큰이 그대로 있다.

첫 질문은 제품 카드의 한 모델 장점을 브랜드 전체 선택 이유로, 배송·설치를 제품 기술 장점으로 잘못 읽었다. 두 번째 질문에는 “한 모델 카드·가격·장바구니”와 “리테일러 배송·설치 서비스”를 각각 제외한다고 명시했다. 그 뒤 같은 두 영역이 검토 메모의 N 후보와 일치했다. **이 결과는 Jev가 수정된 제외 문구에 반응했음을 보여 줄 뿐, ID19·20 판정 능력의 독립 검증이 아니다.** 질문을 고치는 데 사용한 바로 그 사례를 재시험했기 때문이다.

`block-00005`는 짧은 소개문과 제품군 링크가 한 영역에 섞여 있다. 질문형 절전 설명이 있어도 이것을 별도의 구조화된 FAQ로 인정할지 판단이 남는다. ID23의 Jev 확신도가 두 번 모두 낮았으므로 Y 근거로 사용하지 않는다. `block-00011`에는 기술 설명과 절전 질문·답변이 함께 있어 ID20·ID23 모두 해당으로 나왔다. [사용자 수정 기준표](../../../../BCP_9개_항목_판정기준_검토표.md)는 질문형 제품 설명에 대응 답변이 있으면 인정하지만, 실제 화면에서 FAQ 블록 구조·표시를 검토해야 페이지 단위로 결론낼 수 있다.

`block-00016`은 질문 제목만 있고 이 BCP 본문에 답이 없어서 ID23 비해당이 적절하다. 그러나 2차 ID20의 비해당 확신도는 0.20으로 낮다. Choice의 확신도는 선택지 확률 분포에서 계산되며 사람 정답률이 아니다. 낮은 값 또는 사람이 보기에 이견이 있는 결과는 그대로 자동 판정으로 쓰지 않는다.

이 파서는 ID20 전용 후보군을 따로 찾지 않는다. 저장된 Coolblue HTML을 구조와 길이로 나눈 19개 영역 중 숨김 단서가 있는 2개를 뺀 17개에 ID19·20·23 질문 초안을 동일하게 붙였다. AI가 그중 5개를 시험용으로 직접 골랐고 배송·설치는 처음부터 제외해야 할 것으로 본 음성 사례였다. 선정한 사례의 Jev 답이 맞도록 질문을 고친 것은 모델의 새로운 판단 능력을 입증하지 않는다.

이번 두 실행은 합계 10건 요청, 각각 7,352개와 7,642개의 입력 토큰을 Jev 응답에서 보고했다. 실제 요청·응답은 각 실행 폴더의 `request-payloads.jsonl`, `responses.jsonl`, `manifest.json`에 남겼다. 처리 시간 비교, 사람 정답 기준 정확도, 전 리테일러 확대 비용은 측정하지 않았다. 2차 질문으로 만든 전체 9개 페이지의 초안은 [별도 결과 묶음](../../20260928T060234KST/20260927T224906827801Z/Jev_파서_요약.md)에 저장했고 전송은 Coolblue 5건만 했다.

다음 검증에서는 화면에 실제 표시된 블록 경계와 질문·답변 구조를 확인하고, 다른 리테일러·언어에서 Y/N 경계 사례를 추가해 정답표를 만든 뒤 Jev 결과를 비교한다. ID18 대표 배너의 화면 상단 위치, ID21·22 링크의 정상 이동, ID8 이미지 범위·alt는 이 시험에서 판정하지 않았다.
