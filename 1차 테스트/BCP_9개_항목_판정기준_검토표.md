# BCP 9개 항목 판정 기준 검토표

작성일: 2026-09-28. 상태: **사용자 수정 반영 — 확정된 조건과 미결 사항 병기**. ID8 이미지 종류의 범위는 D019로 확정했고 [9개 대표 페이지 1차 판정](bcp-zyte-poc/results/20260928T060234KST/판정_1차_요약.md)과 [전체 159개 URL 1차 판정](bcp-zyte-poc/results_population/20260928-all-159/전체_URL_판정_진행상태.md)에 적용했다. ID18~23도 저장 화면·본문과 검사한 링크를 근거로 1차 판정했으나, 아래 미결 경계와 수집 문제는 검토 필요로 남긴다.

BCP는 리테일러 안의 특정 브랜드·제품군 페이지(Brand Category Page)다. 이번에는 페이지 한 개의 항목별 충족 여부를 정하며, 여러 페이지의 점수·비중 집계는 다루지 않는다.

## 읽는 방법과 출처

- **원문:** 『EY_LGE HS 온라인 리테일 클리닉 진단 항목_v1.95_20260915 (1).xlsx』의 `Clinic 진단 항목` 탭, 해당 ID의 `정의`, `진단 항목 상세`, `점수화 기준` 열. 아래 원문 열의 링크로 해당 행의 추출본을 확인할 수 있다.
- **기록된 결정:** [프로젝트 결정 기록의 2026-09-28 BCP 1차 판정 기준 선택](../docs/DECISIONS.md#2026-09-28-bcp-1차-판정-기준-선택)에 저장된 선택을 보존했다. 이 요청에서 새로 확정한 것으로 기록하지 않는다.
- **제안:** 원문과 기록된 결정만으로 정해지지 않은 빈값·최소 개수·제외 사례 등의 처리안이다. 아래 Y/N/검토 필요 열은 원문을 구현하기 위한 **초안**이며 아직 전체 승인된 규칙이 아니다.
- 상세 설명이 필요한 경우 [상세 기준 초안](BCP_9개_항목_판정기준_초안.md)을 참고한다. 이 검토표는 중복·충돌 처리처럼 상세 초안에서 선택이 필요한 부분을 명시적으로 드러낸다. 기존 문서나 사용자 결정을 자동으로 대체하지 않는다.

## 2026-09-28 수정 반영

[결정 기록 D018](../docs/DECISIONS.md#2026-09-28-bcp-판정-기준-후속-수정)에 따라 ID8·18·19·20·21·22·23의 아래 조건을 갱신했다. 확정된 조건은 **확정**으로 표시한다. ID23의 “인정해”는 질문·답변 한 쌍과 질문형 제품 설명(대응 답변 있음)을 모두 인정하는 뜻으로 해석했다. [D019](../docs/DECISIONS.md#2026-09-28-id8-대상-이미지-범위-확정)로 ID8의 제품 카드 포함·CSS 배경 및 순수 장식 제외도 확정했다. ID9·10은 이번 수정 대상이 아니다.

## 공통 판정 원칙 — 제안

| 결과 | 의미 |
| --- | --- |
| Y | 항목의 필수 조건을 충족하는 근거를 확보함 |
| N | 필요한 영역·동작을 충분히 확인했고, 필수 조건을 충족하지 않음 |
| 검토 필요 | 기준 미확정, 추출 누락 가능성, 표시 상태 미확인, 링크 검사 불가 등으로 확정하기 어려움 |

**ID20 예외:** 정상 수집한 내용의 USP 여부가 애매하면 사용자 결정에 따라 N으로 기록하고, 이유를 ‘USP 여부 불명확’으로 남긴다. 수집 실패와 비대상은 위 결과와 별도 상태로 저장한다. 파서가 후보를 0개 찾았다는 사실만으로 N을 부여하지 않는다. N의 근거는 검색어 불일치가 아니라 필요한 영역을 확인한 결과여야 한다.

화면 콘텐츠는 BCP 본문을 대상으로 한다. 리테일러 공통 헤더·푸터·쿠키 창과 사용자가 열 수 없는 숨은 템플릿은 제외하는 것을 제안한다. 접혀 있어도 사용자가 정상적으로 펼쳐 볼 수 있는 본문 콘텐츠는 인정한다. 메타데이터와 Canonical은 HTML의 문서 정보 영역에서 확인한다.

전체 화면 이미지의 10,000픽셀 이후 잘림은 이미 허용된 사항이다. 다만 특정 항목에 필요한 표시 여부·이미지 내용 등의 근거가 부족하면 해당 항목만 검토 필요로 둔다.

## 코드에 적용하기 전 확인

이 표는 판정 정책 검토를 위한 문서다. 현재 파서는 전체 본문 의미, 모든 블록의 표시 위치, CSS 배경 이미지, 링크의 실제 도착 결과를 모두 제공하지 않는다. 기준이 정해지면 필요한 정보가 있는지 먼저 대조하고 수집·파서를 보완한다. 후보 0개를 그대로 N으로 바꾸는 규칙은 적용하지 않는다.

수정 사항은 `ID18: 영상 배너도 인정`, `ID21: 같은 페이지 필터 이동도 인정`처럼 항목 번호와 원하는 조건으로 남길 수 있다. 확정된 변경만 프로젝트 결정 기록과 기준 문서에 반영하고, 그다음 코드 또는 Jev가 사용할 질문으로 옮긴다. Jev 사용 자체는 아직 채택 결정이 아니다.
